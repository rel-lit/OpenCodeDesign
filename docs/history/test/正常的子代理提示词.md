## 1. 概述

《深渊弹幕》是一款卡通渲染风格的 2D 俯视角硬核 Roguelike 射击游戏。玩家探索随机生成的地下城，利用独特的**元素反应系统**与敌人战斗，收集武器和道具，逐层深入直至挑战最终 Boss。

### 核心设计原则
- **易上手难精通**：基础操作简单（移动+射击+翻滚），但元素反应系统提供深度策略空间
- **Roguelike 永久死亡**：每次死亡重新开始，但可解锁全局进度
- **鼓励实验**：元素组合没有"唯一正解"，不同组合在不同场景各有优劣

---

## 2. 视觉与风格

- **视觉风格**：卡通渲染（Cartoon Rendering）— 色彩鲜明、角色圆润、明亮轻快
- **视角**：俯视角（Top-down）
- **氛围**：在轻松明亮的卡通画风下隐藏着硬核的挑战

---

## 3. 核心玩法循环

```
进入地下城层 → 探索随机房间（战斗/宝箱/商店/隐藏）
→ 收集武器 + 元素道具 → 利用元素反应连锁清场
→ 击败层 Boss → 进入更深处 → 直至挑战最终 Boss（或死亡）
```

## 4. 战斗系统

### 4.1 基础操作
- **左摇杆/WASD**：移动
- **右摇杆/鼠标**：瞄准
- **左键/RT**：射击
- **空格/RB**：翻滚（带无敌帧，短冷却）
- **Q**：使用主动道具
- **E**：切换武器

### 4.2 翻滚回避
- 持续时间约 0.3 秒，全程无敌帧
- 冷却约 0.8 秒
- 可翻滚穿过敌人和子弹

## 5. 核心创新：元素反应系统

这是本游戏区别于《挺进地牢》的标志性系统。

### 5.1 元素类型

| 元素 | 基础效果 | 图标颜色 |
|------|---------|---------|
| 🔥 火 | 灼烧持续伤害 | 红/橙 |
| 💧 水 | 减速敌人、熄灭火焰 | 蓝 |
| 🛢️ 油 | 铺油面使敌人滑倒 | 棕 |
| ⚡ 电 | 麻痹敌人短暂定身 | 黄 |
| ☠️ 毒 | 中毒持续伤害 | 紫/绿 |

### 5.2 元素组合反应表

| 组合 | 反应效果 |
|------|---------|
| 火 + 油 | **大爆炸**：范围高额伤害 |
| 火 + 毒 | **毒气云**：大范围持续毒伤害 |
| 水 + 电 | **连锁电击**：全场传导 AOE |
| 电 + 金属（环境） | **电磁场**：范围内持续伤害+麻痹 |
| 水 + 毒 | **污染水域**：触碰即中毒 |
| 油 + 毒 | **毒雾**：减速+持续伤害区域 |

### 5.3 元素附魔

玩家可以拾取**元素附魔道具**，将其镶嵌到武器的元素槽中：
- 给武器附魔元素 → 射击附带该元素效果
- 武器稀有度越高，可镶嵌的元素槽越多（0~2 槽）
- 传说级武器有特殊元素效果

### 5.4 环境交互
- 场景中的水坑、油桶、电路、火焰等可被武器触发
- 利用地形智取敌人：射击油桶引燃、水坑导电等

## 6. 武器系统

### 6.1 稀有度等级

| 稀有度 | 颜色 | 元素槽 | 特点 |
|--------|------|--------|------|
| 普通 🟢 | 白色 | 0 | 基础武器，稳定可靠 |
| 精良 🔵 | 蓝色 | 1 | 较高伤害/射速，偶尔带元素 |
| 稀有 🟣 | 紫色 | 1~2 | 特殊射击模式（散射/追踪/蓄力） |
| 史诗 🟠 | 橙色 | 2 | 高伤害 + 独特机制 |
| 传说 🔴 | 红色 | 2+特殊 | 改变游戏规则的强力武器 |

### 6.2 武器类型
- 手枪（均衡）
- 霰弹枪（近距离高伤）
- 冲锋枪/机枪（高射速）
- 步枪（精准远程）
- 火箭筒/榴弹（范围伤害）
- 特殊武器（如"丢出回旋镖的枪"、"射出水球的枪"等脑洞设计）

### 6.3 切换机制
- 玩家可携带 **2 把武器** 随时切换
- 可通过道具解锁第 3 武器槽

## 7. 道具系统

### 7.1 被动道具
拾取后永久生效，可叠加：
- 属性提升：移速、射速、伤害、翻滚距离
- 元素强化：提升特定元素伤害、扩大反应范围
- 防御类：受伤概率不消耗红心、元素护盾

### 7.2 主动道具
按 Q 使用，有冷却时间：
- 全屏元素引爆
- 元素风暴（召唤大量元素弹幕）
- 元素护盾（免疫伤害+元素反弹）
- 元素核心转化（改变反应规则，如"火+水=蒸汽致盲"）

### 7.3 元素核心（特殊道具）
改变元素反应的基础规则，例如：
- 「熵增核心」：火+冰=爆炸，而非互相抵消
- 「混沌核心」：每次元素反应额外触发一次随机反应
- 「纯净核心」：所有元素伤害提升50%，但无法组合反应

| 👑 Boss房 | 5% | 击败 Boss 进下一层 |

### 8.2 楼层结构

| 楼层 | 主题 | 元素倾向 | Boss |
|------|------|---------|------|
| 第1层 🏛️ | 废弃地牢入口 | 混合 | 岩石傀儡（近战+落石） |
| 第2层 🌋 | 熔岩矿洞 | 火+油 | 火龙王（喷火+流星雨） |

| 第5层 💀 | 深渊之底 | 全元素 | 混沌之核（全元素形态转换） |

### 8.3 生成规则
- 每层随机生成 8~15 个房间
- 房间之间以走廊/门连接
- Boss 房始终在层的最远端
- 商店和宝箱房偏向出现在中段

### 9.2 Boss 设计原则
- 每个 Boss 有 2~3 个阶段
- 阶段切换时攻击模式变化
- 有元素抗性和弱点
- 击败后掉落稀有武器/道具 + 通往下一层的传送门

## 11. 技术架构要点

### 11.1 开发环境
- 引擎：推荐 Godot 4 / Unity 2D
- 语言：C# / GDScript
- 平台目标：PC（Steam）

### 11.2 核心架构模块
1. **关卡生成器（Room Generator）**：随机房间拼接 + 内容填充
2. **元素反应系统（Element System）**：管理元素状态、组合检测、反应触发
3. **弹幕管理（Bullet Manager）**：大量子弹的对象池优化
4. **武器系统（Weapon System）**：武器数据配置、射击模式、弹药管理
5. **道具系统（Item System）**：道具效果注册、叠加逻辑
6. **敌人 AI（Enemy AI）**：行为树/状态机驱动的敌人行为

---

## 12. 设计约束与原则

- **YAGNI**：不做多余的社交、排行榜、每日挑战等外围系统
- **聚焦核心玩法**：战斗 + 元素反应 + 探索的闭环做到极致
- **可测试性**：每个系统模块独立可测
- **数据驱动**：武器、道具、敌人、房间配置均使用数据文件，方便迭代调整
